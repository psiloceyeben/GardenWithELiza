## Files and use

Each design has a 1080×1080 square PNG and a 1080×1350 portrait PNG, plus a
self-contained HTML source. Rendered with actual existing game sprites, arranged
as promotional artwork—not presented as gameplay screenshots. No future-3D
mockups, financial promises or external account publishing are included.

Render source: tools/render-promo.cjs (run only on Box C). All six files passed
headline/footer geometry checks and promotional copy checks against the project's
prohibited-phrase list. Visual review is recorded in the task, not a claim of
platform-specific campaign approval.
