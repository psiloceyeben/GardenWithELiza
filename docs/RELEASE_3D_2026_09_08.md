# 3D release to production — 2026-09-08 21:21 UTC

Ben authorized porting the current 3D build to the live site. Done as a paired
server+client release. This is Phase B of `FINISH_PLAN_2026_09_08.md`.

## What shipped

- **Client**: `assets/index-DdME0LY0.js` (built on Box C 12:16 UTC from the source
  now committed as `0748862`; verified no client/shared source is newer than the
  build, and `view-mode.ts` / `Renderer3D.ts` / `game.ts` hashes match the commit).
  Default view is perspective + Wander characters. `view=orthographic`,
  `characters=sprites` and `r=2d` remain as fallbacks.
- **Server**: `/opt/pons/server/dist` compiled 12:57 UTC (only a test file is newer),
  now running on the patched **Node v22.23.2** instead of the system v22.11.0.
- Previous live bundle was `index-Biaq2647.js` (HD-2D partner preview).

## Order and safety

Server first, then client: the new client depends on new protocol variants
(position correction, carry appearance, session-replaced 4001, identity 4003,
skin/hair fields). An old client against the new server degrades gracefully.

Old fingerprinted asset chunks were copied into the new site so already-open tabs
can still fetch theirs.

## Backups

- Box C `/opt/pons/release-backup-20260908-212046/`: `live-data.tgz` (captured with
  the service stopped), `server-dist.tgz`, `pons-server.service.before`.
- Box A `/var/www/pons.before-3d-20260908-212111/`: the previous static site.

Rollback: stop `pons-server`, restore `server-dist.tgz` and the `.before` unit file,
`systemctl daemon-reload && start`, then move the Box A backup directory back over
`/var/www/pons`. Preserve current player data first; do not restore old data over it.
