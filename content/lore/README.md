# Pons Garden lore corpus

Plain-prose documents describing the village, its people, its plants and its rules. This is the admitted corpus for a
dedicated Pons Garden Oracle instance (same recipe as the HOODBarons instance on Box C :8098: compile from a corpus,
serve `/chat`, point `PONS_ORACLE_URL` at it). Until that instance exists, the game server asks the general Oracle.

Every file here is user-facing text in spirit and is linted against `shared/banned-copy.json` like the rest of `content/`.
No token, stock, or yield language belongs in this folder (bible I-4).
